# Rogue 3C 出招克制规则

本文档将 `rouge3c出招表.xlsx` 转为项目内可维护的文字规范。若代码与本文档不一致，先以本规则表核对设计意图，再决定是否修改实现。

## 基本约定

- 对局双方同时出招；下列每条均按“左侧招式 vs 右侧招式”描述。
- `无伤`表示使用该招式的一方不受到这组对抗造成的伤害。
- `-10`、`-30`是本次克制关系的基础伤害，**不享受攻击、装备、技能或芯片加成**。
- 同一招式多次出牌时，按每一段分别结算。特别说明中的“第 2 次/第 3 次”表示对方第一层酒/桃抵挡后，剩余段数造成的额外基础伤害。
- 桃和酒都有“一次免伤 + 未触发时的自身效果”两部分：被攻击命中时先抵挡一次伤害并失去回复/酒效果；未命中时保留回复或酒效果。
- 冰杀对【顺手牵羊】的冻结归属已按确认修正：**使用顺手牵羊的一方获得冰冻**。
