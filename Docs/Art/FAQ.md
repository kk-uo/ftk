# Art FAQ

## 为什么 PNG 不透明？

常见原因：

- AI 导出时带了纯色背景。
- 抠图没有真正删除背景。
- 图片被保存成不带 Alpha 的格式。
- 使用了 JPG 或其它不支持透明的格式。

处理方式：

- 重新导出 PNG。
- 确认图像有 Alpha 通道。
- 在图像编辑器中检查棋盘格透明背景。
- 特效、角色、武器、图标必须透明。

## 为什么图片发白？

常见原因：

- 半透明边缘被错误预乘。
- 导出时带了白色底。
- Godot 导入压缩参数不适合该图片。
- 图片本身亮度过高，放在深色 UI 上显得发灰。

处理方式：

- 检查源图 Alpha。
- 重新导出透明 PNG。
- 检查 Godot Import 设置。
- 对 UI 图标做深色描边或阴影。

## 为什么图片模糊？

常见原因：

- 源图尺寸太小。
- UI 中被放大过多。
- 导入设置启用了不合适的过滤。
- 图片不是按目标分辨率制作。

处理方式：

- 背景按 `2560 x 1440` 制作。
- 图标至少 `128 x 128`。
- 需要像素清晰时检查过滤设置。
- 不要用小图强行拉伸成大图。

## 为什么 Godot 没刷新资源？

常见原因：

- 文件还没有保存到项目目录。
- Godot 编辑器没有检测到文件变化。
- `.import` 文件状态异常。
- 文件名大小写或路径变化导致旧引用仍存在。

处理方式：

- 回到 Godot 等待自动 Import。
- 手动切换目录或重启编辑器。
- 确认文件确实在 `Assets/` 下。
- 避免只改大小写的文件名。

## 为什么图片显示不出来？

常见原因：

- 放错目录。
- 文件名和引用 ID 不一致。
- 未来 Database 没注册。
- Godot Import 失败。
- 图片 Alpha 全透明。

处理方式：

- 检查目录。
- 检查命名。
- 检查 Godot Import。
- 用图片编辑器确认内容不是全透明。
- 未来接入 Database 后检查注册 ID。

## 资源放错目录怎么办？

如果资源尚未被代码或场景引用，可以移动到正确目录。

如果资源已经被 Godot 场景或代码引用：

1. 先确认引用位置。
2. 修改引用或未来 Database 注册。
3. 再移动资源。
4. 重新打开 Godot 检查 Import。
5. 运行游戏验证显示正常。

不要随意移动已有资源，尤其是已经生成 `.import` 并被场景引用的文件。

## 为什么不允许中文文件名？

中文文件名在部分工具链、脚本、版本管理和跨平台路径处理中更容易出错。

项目内部统一使用英文小写和下划线，可以降低引用错误，并方便未来 Database 使用稳定 ID。

## 为什么不能直接在代码里 Load 图片？

直接 `Load()` 会让资源路径散落在代码中。

后续如果替换图片、重命名目录、做缓存、做皮肤或做语言差异资源，会需要修改很多地方。

未来应通过：

- `SpriteDatabase`
- `AnimationDatabase`
- `AudioDatabase`
- `EffectDatabase`

统一引用资源。
