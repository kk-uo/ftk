# Characters 角色资源

## 存放内容

这里存放玩家角色相关资源。

- `Portraits/`：角色头像，用于角色选择、状态面板、图鉴和技能触发提示。
- `BattlePortraits/`：战斗中使用的角色立绘或战斗形象。
- `Icons/`：角色小图标、阵营图标或状态用头像。
- `MapSprites/`：地图探索中移动的小人立绘。

## 命名规范

```text
zhao_yun.png
battle_zhaoyun.png
icon_zhaoyun.png
map_zhaoyun.png
```

角色名使用稳定英文 ID，和角色数据库 ID 保持一致。

## 推荐尺寸

- 头像：`1254 x 1254`，与赵云头像保持完全一致的正方形比例。
- 战斗立绘：`1024 x 1536` 或同等比例
- 小图标：`128 x 128`
- 地图小人：`128 x 128`

## 头像背景与风格

全部角色头像使用赵云头像同一套赛博三国像素风：深色背景、青色霓虹主光、少量品红边缘光，
并保持不透明的方形构图。这样在角色选择、状态面板和技能提示中缩放时不会露出不一致的底色。

战斗立绘、图标和地图小人是否透明，按各自的表现需求决定。

## 引用系统

未来由以下系统引用：

- `CharacterVisualDatabase`
- 角色选择 UI
- 战斗 UI
- 地图探索角色 `MapPlayer`
- 图鉴
- 事件角色展示

不要在 UI Controller 中直接加载角色图片路径。
